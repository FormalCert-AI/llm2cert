# DynaCertBench

The benchmark contains 105 problems: 80 literature-derived, 11 extended, and 14 new systems.

- `dynacertbench_executable.json`: the inputs read by the pipeline.
- `dynacertbench_by_problem.json`: task descriptions and literature references.
- `benchmark_curation_counts.json`: source and curation counts used in the paper.

See the source references in the descriptive dataset when reusing an individual benchmark problem.
